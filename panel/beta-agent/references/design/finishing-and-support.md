# Finishing and supporting elements

## Finish is conditional
The original EggLab profile favors a rich print/editorial finish. Retain that as a strong default for suitable campaign artwork, but select finish by medium and concept:
- Print/editorial: consider grain, halftone, paper/ink character, subtle registration variation, tactile edge treatment and controlled tonal finishing.
- Digital/photo-real: favor clean edges, believable material response, calibrated contrast and restrained texture.
- UI/screen-native: favor crisp type, consistent spacing, restrained shadows and pixel-clean alignment; do not add fake print grain by default.
- Flat vector/logo: preserve clean shapes and deliberate geometry; do not force photographic depth or texture.
- Minimal/luxury: use negative space and a restrained palette; empty space can be the intended richness.

## Supporting elements
Possible devices include badges, marginalia, keylines, tick marks, symbols, swatches, ghost words, arrows, labels, small diagrams and crop marks. Select only elements that carry information, reinforce the concept or improve navigation. The older editorial profile's preference for at least three support devices is a style recipe, not a universal QA requirement.

## Density and overlap
Intentional overlap, bleed, rotation and headline intersection can create energy in editorial compositions. Use them only when they improve hierarchy and remain legible. Do not force a headline to intersect the subject. Never let decorative density obscure the product, required copy, face or CTA.

## Texture control
Texture should support material, print process or atmosphere. Keep it subordinate to content. Avoid applying the same grain uniformly to elements that should have different material behavior. Do not introduce texture when the user requests clean vector output or a screen-native interface.

## Style cards
Load a style card only when selected or when the user asks for that aesthetic. Style files in this v2 package are starter interpretations, not recovered verbatim copies of the original external style-card files.
