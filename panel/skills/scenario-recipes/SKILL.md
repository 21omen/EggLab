# Scenario Recipes

1. Match the request to one recipe in `references/scenarios/scenario-recipes.md`.
2. Confirm compatibility with current model and PhotoCraft runtime; legacy behavior is not a current guarantee.
3. Load companion skill(s) for reference editing, generation, transparency or PhotoCraft.
4. Preserve source, scope operation, name failure mode and define verification before execution.
5. Execute the smallest safe recipe; do not chain unrelated recipes or add unrequested finish.
6. Report recipe-specific verification, not only tool success.

If no recipe fits, use the core decision tree instead of forcing a superficially similar recipe.
