# Design Direction

Activate for new design, poster, advertisement, packaging, campaign artwork, brand-led composition or subjective design review.

1. State the job in one sentence: audience, medium/placement and desired action/feeling.
2. Separate fixed content from open decisions; preserve exact strings and supplied facts.
3. Run the **anti-default pass** before concepts:
   - name the obvious solution the category would produce;
   - state why it is generic (stock food photo, centred headline, red badge, arbitrary gradient, etc.);
   - find one specific detail in the project — place, material, audience, product, language, ritual or constraint;
   - generate 3–5 directions that differ **in kind**, not five layouts of the same idea;
   - select one and give the reason it fits this project.
4. Pull the alternatives from different **method lenses**, not random style cards:
   - typographic (the message is the form),
   - physical/material (the piece behaves like paper, fabric, metal, food),
   - documentary/observed (a real place, person or process),
   - abstract/systemic (diagram, grid, data, ritual structure),
   - product-specific (a detail only this subject has).
   Do not use randomness or forced weirdness as a substitute for relevance. A direction is different only when the difference has a reason in the brief.
5. Choose the visual method before the finish: a print should feel printed, a photograph should behave like photography, a 3D render should keep clean geometry and physical light, a vector mark should stay vector. Do not let a generic AI finish erase the method.
6. Select one concept and express it in a short phrase. One dominant visual idea per piece.
7. Set format/safe zones/grid, then composition, focal subject, palette, typography and finishing treatment—in that order.
8. Choose a visual profile before loading a style card. Load one matching card only when useful; do not force a random card.
9. Design for target viewing size; check thumbnail hierarchy and two-second comprehension.
10. Each support element must clarify, identify, structure or create deliberate rhythm.
11. Hand off direction to asset planning and PhotoCraft as needed.

**Heuristics, not laws:** one dominant focal point; usually no more than two type families; generous margins unless a bleed is intentional; coherent light/material behavior. A single-object ad may use a large hero, but place/mood work may prioritize space. Photography is a strong default for physical realism; illustration is right when its language is the idea.
