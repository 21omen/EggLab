# Asset Planning

1. Read brief and direction; list each visible element and role.
2. Assign L0–L7 roles from `references/asset-planning/asset-stack.md`.
3. Choose per element: editable type, vector shape/fill, transparent generation, reference edit, full-frame scene or PhotoCraft effect.
4. Split elements needing separate control (product/exact label, subject/backdrop, type/photograph).
5. Write a 15–30-word world line for light, camera feel, palette, materials and finish.
6. For recurring people/characters define one approved identity anchor; give every other reference one job.
7. Plan render count and dimensions from displayed footprint. Small props need not be full-canvas size.
8. Explore only to resolve real uncertainty; no exploratory renders after direction is clear.
9. Assemble bottom-up with named independent layers. Never flatten independent assets to combine them.
10. Record asset mode, dimensions, references, dependencies, render budget and QA evidence.

Text-only, vector-only, deliberately minimal or review-only work can use zero image renders. The v1 “hero plus one additional render” remains a richness baseline for image-led work, not a universal rule. Load the asset-stack reference for multi-asset jobs.
