# PhotoCraft: layers, masks and adjustments

## Layer discipline
- Keep source, generated assets, retouch, effects, vector and type on separate named layers/groups.
- Name layers by content and role, not temporary tool actions.
- Preserve order and original content. Duplicate before destructive edits when necessary.
- Do not flatten, merge or delete user layers as a shortcut. If a requested deliverable needs a flattened export, export a copy while preserving the editable project.
- Verify layer visibility, blend/opacity/transform and group membership after batch operations.

## Masks and selections
Choose subject/object/rect/lasso selections according to edge complexity. Refine selection where needed. Use reveal/hide masks to preserve reversibility. Apply a mask only when necessary and retain a backup where possible. Inspect hair, glass, translucent surfaces, fine product edges and intersections.

## Adjustments
Prefer adjustment layers and clipping masks for grade, curves, hue/saturation and gradient mapping. Make changes locally when only one layer/region needs adjustment. Avoid clipping a global grade to the wrong group or unintentionally shifting brand/product colors.

## Transform and placement
Preserve aspect ratio unless distortion is intentional. Confirm perspective, scale, ground plane, baseline and contact points. Check that a transformed asset does not create an accidental crop or edge collision.

## Safe operation sequence
Inspect → duplicate/backup if required → select target → apply reversible operation → inspect result → audit → save. When an operation is destructive or the command's reversibility is unknown, stop and request approval or use a safe duplicate.
